# Rocket.Chat Contributions Log

A running log of my work contributing to [Rocket.Chat](https://github.com/RocketChat/Rocket.Chat) —
issues I've investigated, bugs I've reproduced, PRs I've opened, and what I'm
learning about the codebase along the way.

I'm building toward a GSoC application, but this repo exists mainly to keep
myself honest and organized: not every day ends in a merged PR, but most days
involve real investigation, and I wanted a place to track that instead of
losing it in browser tabs and closed issues.

## Structure

- 📓 [`logs/`](./logs) — short daily entries: what I looked at, what I learned, what's next
- 🔍 [`investigations/`](./investigations) — deeper notes on specific issues, including repro scripts where relevant
- 🧠 [`architecture-notes/`](./architecture-notes) — notes on how Rocket.Chat is structured, as I learn it
- 📋 [`pr-tracker.md`](./pr-tracker.md) — table of every PR/issue I've opened or worked on, with status
